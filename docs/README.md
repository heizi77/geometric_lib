# Документация geometric_lib

Библиотека содержит функции для расчета основных геометрических параметров (площади и периметра) для плоских фигур: круга, квадрата, прямоугольника и треугольника.

## Общее описание

Проект состоит из четырех модулей. Каждый модуль отвечает за отдельную геометрическую фигуру и содержит функции вычисления площади (`area`) и периметра / длины окружности (`perimeter`):

* `circle.py` — круг
* `square.py` — квадрат
* `rectangle.py` — прямоугольник
* `triangle.py` — треугольник

---

## Описание функций и примеры использования

### 1. Круг (`circle.py`)

#### `area(r)`
Считает площадь круга.
* **Аргументы:** `r` — радиус круга (`int` или `float`).
* **Возвращает:** площадь круга (`float`).

```python
from circle import area

s = area(5)
print(s)  # 78.53981633974483
```

#### `perimeter(r)`
Считает длину окружности.
* **Аргументы:** `r` — радиус круга (`int` или `float`).
* **Возвращает:** длину окружности (`float`).

```python
from circle import perimeter

p = perimeter(5)
print(p)  # 31.41592653589793
```

---

### 2. Квадрат (`square.py`)

#### `area(a)`
Считает площадь квадрата.
* **Аргументы:** `a` — длина стороны (`int` или `float`).
* **Возвращает:** площадь квадрата (`int` или `float`).

```python
from square import area

s = area(4)
print(s)  # 16
```

#### `perimeter(a)`
Считает периметр квадрата.
* **Аргументы:** `a` — длина стороны (`int` или `float`).
* **Возвращает:** периметр квадрата (`int` или `float`).

```python
from square import perimeter

p = perimeter(4)
print(p)  # 16
```

---

### 3. Прямоугольник (`rectangle.py`)

#### `area(a, b)`
Считает площадь прямоугольника.
* **Аргументы:** `a`, `b` — длины сторон прямоугольника (`int` или `float`).
* **Возвращает:** площадь прямоугольника (`int` или `float`).

```python
from rectangle import area

s = area(3, 5)
print(s)  # 15
```

#### `perimeter(a, b)`
Считает периметр прямоугольника.
* **Аргументы:** `a`, `b` — длины сторон прямоугольника (`int` или `float`).
* **Возвращает:** периметр прямоугольника (`int` или `float`).

```python
from rectangle import perimeter

p = perimeter(3, 5)
print(p)  # 16
```

---

### 4. Треугольник (`triangle.py`)

#### `area(a, h)`
Считает площадь треугольника по стороне и опущенной на нее высоте.
* **Аргументы:** 
  * `a` — сторона треугольника (`int` или `float`).
  * `h` — высота, опущенная на сторону `a` (`int` или `float`).
* **Возвращает:** площадь треугольника (`float`).

```python
from triangle import area

s = area(4, 5)
print(s)  # 10.0
```

#### `perimeter(a, b, c)`
Считает периметр треугольника по трем сторонам.
* **Аргументы:** `a`, `b`, `c` — длины сторон треугольника (`int` или `float`).
* **Возвращает:** периметр треугольника (`int` или `float`).

```python
from triangle import perimeter

p = perimeter(3, 4, 5)
print(p)  # 12
```
